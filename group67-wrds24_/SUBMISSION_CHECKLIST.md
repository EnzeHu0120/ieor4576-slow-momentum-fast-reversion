# ZIP submission checklist

- Read START_HERE.md and the English PDF.
- Fixed inputs and three verified reference archives are included in this private ZIP.
- Run `python run_all.py` to rebuild the completed analysis without retraining.
- Full estimation is a separate, expensive option; it was not rerun for packaging.
- Partial replication, conditional evaluation, cost sensitivity and proposed future
  work are explicitly distinguished in the report.
- Upload to the course system and verify receipt; submission is a team action.
- Preserve data-sharing restrictions. Do not make this private package public.
