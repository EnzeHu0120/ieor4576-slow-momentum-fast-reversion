# Paper #67 replication protocol

**Primary:** Wood, Roberts & Zohren (2022), *Slow Momentum with Fast Reversion: A Trading Strategy Using Deep Learning and Changepoint Detection*, arXiv:2105.13727.

## Required ablation
Compare **252-session TSMOM**, **63-step LSTM Deep Momentum Network**, and **63-step LSTM + online Gaussian-process CPD**, especially **CPD lookback 21 and 63 trading sessions**, matched to the same data, training periods, volatility scaling, and costs. Other CPD horizons (10/126/252) optional. The published Exhibit 3 reports *pre-cost* Sharpe 1.62 LSTM vs 2.16 optimized-CPD LSTM; those are **not our team's estimates**. Extend Appendix C by measuring the effect of 0, 1, 2, 3 and 5 basis points **one-way traded-notional cost**.

## Model inputs and objective
Use normalized lagged 1/21/63/126/252-session returns and normalized MACD with trailing 60-session EWMA volatility; note paper text sometimes specifies 256 instead of 252 and reconcile with source. CPD compares a Matérn 3/2 GP with and without a change-point kernel on each trailing standardized return window and outputs **severity nu** and **relative location gamma**. Inputs/GP fitting use only data available at the decision date. The LSTM outputs a tanh signal `X ∈ [-1,1]`, directly optimized by negative annualized Sharpe of next-period, volatility-scaled captured returns. Validate network hyperparameters and early stopping on pre-test data only.

Scale risk exposures by `w(i,t) = X(i,t)*0.15/(N*sigma_annual(i,t))` with annualized volatility from past EWMA data, position caps and identical timing. Define `h(i,t+1)` as exposure actually held for the return interval ending at t+1: idealized timing uses `w(i,t)`, while a one-session delay uses `w(i,t-1)`. Then `R_gross(t+1) = sum_i h(i,t+1)*r(i,t+1)` and `R_net(t+1) = R_gross(t+1) - cost_bps*0.0001*Q(t+1)`, with `Q(t+1) = sum_i abs(h(i,t+1)-h(i,t))` charged when those interval holdings are established. For a roll use the absolute old plus new contract exposures. Audit embedded index-roll treatment to avoid duplicate charges. Include entry, exit, reversal, volatility-driven resizing and **both legs of futures rolls**. Shared generic backtest's lag=2 is a conservative execution-timing scenario; assess paper-alignment separately. The 15% is a per-asset pre-averaging risk target, not guaranteed portfolio volatility.

## Data and defensible split
The author used 50 Pinnacle CLC futures, 1990–2020, with five-year expanding OOS tests from 1995 through 2020; original proprietary data are not bundled. Team reports **LSEG Datastream via WRDS** E-mini continuous excess-return index **ISMCS04, 4,033 daily rows**, plus expiry metadata for **64 quarterly contracts**. Proposed substitute sample is 2010–2025, expanding to other futures after verifying comparable coverage. These numbers are teammate-reported and need final independent source/roll audit. **This is a methodological / partial replication**, not a reproduction of the author's numerical table.

Provisional strictly chronological WRDS split: **2010–2016 train; 2017–2018 validation; 2019–2020 locked test**; optionally independently report 2021–2025 with frozen design/refits using prior data only. No future-aware asset selection, rolling normalization, CPD, validation tuning or backfilled observations. Purge labels crossing split boundaries. Index excess returns and contract-level executable settlement returns have distinct meanings; expiration dates alone do not reconstruct vendor index rolls. Handle nonpositive futures prices with audited contract-dollar P&L or disclosed exclusion.

## Evaluation and optional extension
Primary outcome: **paired out-of-sample net Sharpe of LSTM+CPD minus LSTM**. Also annualized gross/net return and volatility, MDD, turnover, cost drag and wealth by date, 21/63 CPD window, common seeds and horizons. Pairwise block bootstrap if enough OOS dates. Only after the above runs, consider an otherwise identical LSTM+CPD trained on a cost-aware net-Sharpe/turnover objective: calculate turnover on *consecutive actual portfolio positions*, not shuffled batch edges. Stop if dataset or compute is insufficient and disclose limitations.
